# シアン監視室の画面確認

実施日：2026年10月15日。最終判定：合格。採用した日本中心・シアンの操作モックを、AppKitウィンドウ内のWKWebViewへ実装しました。

## 比較の条件

参照は既存の `cyan-wide.png`（1056×1004、外周余白を含む）です。実装は1024×970のPlaywright画像を比較しました。参照は再現操作後の6件、実装は5件の固定データであり、完全なピクセル一致の判定ではありません。実データ経路は別途、実MacアプリのWKWebViewから1120×820と最小860×650の画像を取得して確認しました。

比較画像は `test-results/dashboard-browser/comparison.png`、固定データ画面は `populated.png`、128件・長いパスの画面は `compact.png` にあります。実アプリの画像は `test-results/dashboard-20261015-161057/` に保存しました。画像はGit管理しません。

## 実アプリ化に伴う意図した変更

- サンプルの「アクセスを再現」を、URLコピー・ローカル検証・公開開始／停止へ変更しました。
- 架空のURL・IP・件数を除去し、Engineが渡す受信値と状態だけを表示します。
- 地図と詳細の「国単位の推定」「表示上の観測点」、DB-IPの版と出典リンクを加えました。
- 外側のモック用背景と角丸枠は除き、Macのウィンドウが外枠を担当します。画面高に応じて地図領域を伸縮します。
- 新規受信の動きは最大8件ずつ。動きを減らす設定と非表示時はアニメーションを抑止します。

## 検証手段の境界

Microsoft PlaywrightのJavaScript APIで、実装HTMLの通常のボタンクリック・行選択・スクロールを確認しました。ネイティブアプリはテスト引数で有効になる入口から同じDOMボタンをクリックし、実Engineを動かしました。画像は実WKWebViewのtakeSnapshotです。OS全体のスクリーンショットや人のマウス操作ではありません。アプリ内組み込みブラウザは使用していません。
